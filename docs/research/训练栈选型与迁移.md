# YuFormer 训练栈选型与迁移（2026-10-18）

## 裁定

YuFormer 的正式训练后端采用 **TorchTitan v0.3.0 + PyTorch 2.14 + FSDP2/DTensor +
Distributed Checkpoint (DCP)**。版本由
`pretrain/backends/torchtitan/backend.lock.json` 固定，任何正式实验必须先通过
`preflight.py`。现有自研 FSDP1 trainer 降级为旧 checkpoint 迁移、数据契约测试和
数值对拍工具，后端名固定为 `pytorch-fsdp1-compat`。

选择 TorchTitan 的原因是它同时满足本项目的两个目标：保留 YuFormer 从零实现的模型，
又使用工业级训练基础设施。v0.3.0 提供 FSDP2、DTensor、TP/PP/CP、选择性重计算、
分布式/异步 checkpoint、可恢复数据加载、Muon、SFT 和 RL 组件。Megatron-Core 0.19
保留为多机扩展与性能对照；0.5B、单机 4×H800 阶段不引入两套正式 trainer。

## 训练配方的默认线

- 优化器以 AdamW 为主线，Muon 作为独立研究臂；在相同 tokens、吞吐与超参搜索预算下比较。
- 学习率以 token 为横轴，默认 warmup-stable-decay；cosine 作为对照。warmup、stable、decay
  三段都写入自包含 recipe，禁止隐藏默认值。
- 主预训练从 4K context 起步。长上下文放在 midtrain，以 4K→16K→64K 渐进扩展；每阶段
  保持全局 tokens/step 可比，并独立验证 RoPE base/缩放方案和短上下文回归。
- BF16 是收敛基线；FP8 只有在 BF16 loss parity、梯度范数和下游评测门禁通过后进入效率臂。
- checkpoint 使用 DCP sharded state，开启异步 staging；同时保存模型、优化器、scheduler、
  dataloader cursor、每 rank RNG 与 run identity。通过 SIGKILL 和跨拓扑 reshard 才算完成。

## 数据与 tokenizer 实验约束

- 每篇文档显式追加 EOD；token stream meta 必须包含 tokenizer SHA、上游 snapshot、全文 SHA、
  文档边界策略和生成配置 SHA。正式 1T 流同时发布 position 序逐文档实际 token 长度清单；
  跨阶段重放门禁按 dataloader 实际监督的 target 前缀计算，并校验清单全文 SHA 与总 token 闭合。
- tokenizer 比较不能直接比较不同词表上的 token-level perplexity。主指标为同一原始 held-out
  文本上的 byte-normalized NLL/BPB，并同时报告压缩率、吞吐、参数量/FLOPs 和下游评测。
- 每个 tokenizer 必须独立物化 train/validation 流；验证数据不得来自训练 order 表。
- 数据 release 必须通过行数守恒、跨源 exact/near dedup、benchmark decontamination、PII/secret、
  license/provenance、人审抽样和 tokenizer 可逆性门禁。任一门禁缺失时状态只能是 blocked。

## Scaling 与架构实验

E1 采用至少三个 compute budget，每个 budget 覆盖 50M/100M/200M/400M/800M 模型；所有点使用
相同 tokenizer、数据分布、scheduler 定义和评测集。拟合 loss(N,D) 时同时报告拟合区间、残差、
bootstrap 置信区间与被剔除 run 的原因。当前 0.5B/1T 仅是待验证候选，不能在 E1 门禁前称为
scaling-optimal。

架构主线保持 dense Transformer。GQA、SwiGLU、RMSNorm、QK-Norm、RoPE、tied embedding 是基线；
gated sliding-window/full-attention 混合属于 YuFormer 研究变量，必须与同参数、同 FLOPs 的全注意力
anchor 对照。64K 路径必须使用 FlashAttention/FlexAttention 或 context parallel，禁止构造
`S×S` dense mask。

## 阶段门禁

1. **D0 数据 release**：数据质量和血缘全部 PASS，生成不可变 dataset id。
2. **T0 tokenizer**：独立验证流与 BPB 报告完成，确定 tokenizer id。
3. **I0 infra**：TorchTitan preflight、4 卡 smoke、SIGKILL 恢复、2↔4 卡 reshard 全部 PASS。
4. **E1 scaling**：预注册矩阵完成，拟合与置信区间可复现。
5. **P0 pilot**：最终候选配置跑 1B tokens，无 NaN、数据断档或吞吐退化，恢复演练通过。
6. **P1 pretrain**：正式预算训练；checkpoint 进入统一 eval 流水线。
7. **M/S/R**：midtrain、SFT、RL 分别有独立数据 release 与回归门禁，不能共用未经审计的临时集。

## 迁移顺序

YuFormer `BaseModel`、预分词 stateful loader、FSDP2 与异步 DCP 适配已落代码。当前并行完成
最终 tokenizer 流物化与 I0 环境升级；随后依次执行单卡数值对拍、4 卡 smoke、SIGKILL 恢复和
2/4/8 卡 reshard canary。通过后运行 E1 scaling。任何正式训练都必须同时引用 PASS data
release、tokenizer gate、immutable run identity 和固定后端 commit。
