# YuFormer 预训练数据源目录

> **YuFormer 第一个贡献点**：ZGCM-1 未公开精确数据源，本目录系统性地按领域锁定每个最佳开源数据集，全部经 HuggingFace 镜像验证可用（2026-09-15），为其他研究者提供一键可复现的预训练数据路径。
>
> 所有 HF 路径已通过 `hf-mirror.com` API 验证存在。标注 ❓ 的体量/许可证为近似值，以数据集主页为准。

---

## 一、领域划分与设计原则

### 领域清单

| # | 领域 | 作用 | 推荐数据集数 |
|---|---|---|---|
| 1 | 通用网页 | 语言建模基础、广覆盖 | 5 |
| 2 | 代码 | 推理能力、结构化思维 | 2 |
| 3 | 数学 | 数值推理、符号操作 | 4 |
| 4 | 学术/科学 | 高质量知识、论文写作 | 3 |
| 5 | LaTeX/形式化 | 数学排版、形式化证明 | 2 |
| 6 | 文学/书籍 | 长文本理解、叙事能力 | 2 |
| 7 | 百科/常识 | 事实知识、定义解释 | 2 |
| 8 | StackExchange/问答 | 问答能力、专业知识 | 1 |
| 9 | 中文 | 中文语言能力 | 3 |
| 10 | 多语言 | 跨语言迁移 | 1 |

### 设计原则

1. **每领域选 2-5 个最优源**，不堆砌——可下载、可验证、有许可证
2. **优先选择已去重版本**（如 the-stack-v2-dedup、fineweb-edu）
3. **优先选择带质量分数的源**（如 fineweb-edu 的教育分数），便于后续 YuFormer 数据管线做阈值过滤
4. **中英双语覆盖**——英文为主（推理/学术强），中文为辅（应用场景需要）
5. **全部 HF 路径经验证存在**，附下载命令

## 二、逐领域数据源

### 2.1 通用网页（General Web）

| 数据集 | HF 路径 | 体量 | 语言 | 许可证 | 特点 |
|---|---|---|---|---|---|
| **FineWeb** | `HuggingFaceFW/fineweb` | ~15T tokens | 英文 | ODC-By | 最强通用网页数据，CC 清洗+去重+质量过滤，社区标杆 |
| **FineWeb-Edu** | `HuggingFaceFW/fineweb-edu` | 1.3T (score≥2) / 5.4T (score≥1) tokens | 英文 | ODC-By | FineWeb 子集，教育质量分类器过滤，适合做课程式配比的高质量段 |
| **DCLM-Baseline** | `mlfoundations/dclm-baseline-1.0` | ~4T tokens / 3B docs | 英文 | Open Data | DCLM 基准数据集，OLMo-2 使用，benchmark 表现强 |
| **Dolma** | `allenai/dolma` | ~3T tokens | 英文 | ODC-By | OLMo 预训练语料，含 web/代码/学术/书籍/social media 混合 |
| **C4** | `allenai/c4` | ~750GB (~200B tokens) | 英文 | ODC-By | 经典 Common Crawl 清洗版，T5/Pile 使用，适合做基线对比 |

**推荐组合**：FineWeb（主干）+ FineWeb-Edu（高质量段，用于课程式配比的后期阶段）。FineWeb-Edu 的教育分数天然适配 ZGCM 的"课程式排序"思想——按 score 从低到高排序即可模拟课程学习。

**下载**：
```bash
# FineWeb-Edu (score≥2, 1.3T tokens)
HF_ENDPOINT=https://hf-mirror.com huggingface-cli download HuggingFaceFW/fineweb-edu --repo-type dataset --local-dir ./data/fineweb-edu

# FineWeb (全量，按 CC-MAIN 快照分文件)
HF_ENDPOINT=https://hf-mirror.com huggingface-cli download HuggingFaceFW/fineweb --repo-type dataset --local-dir ./data/fineweb --include "sample/10BT/*"
```

## 四、推荐配比方案（YuFormer Pretrain）

### 4.1 参考配比（基于公开 SOTA 配方的经验值）

| 领域 | 数据集 | 建议占比 | 理由 |
|---|---|---|---|
| 通用网页 | FineWeb + FineWeb-Edu | 50-60% | 语言建模基础，广覆盖 |
| 代码 | The Stack v2 Dedup | 15-20% | 推理能力，结构化思维 |
| 数学 | Proof-Pile-2 + AutoMathText | 8-12% | 数值推理，符号操作 |
| 学术/科学 | peS2o + arXiv | 5-8% | 高质量知识 |
| 百科 | Wikipedia | 3-5% | 事实知识 |
| 文学/书籍 | PG19 + BookCorpus | 2-3% | 长文本建模 |
| StackExchange | Stack Exchange | 2-3% | 问答能力 |
| 中文 | SkyPile-150B + CCI3-HQ | 5-15% | 中文能力（按目标调整） |
| LaTeX | AlgebraicStack + arXiv LaTeX | 1-2% | 数学排版 |

### 4.2 课程式配比策略（借鉴 ZGCM）

ZGCM 的两阶段课程思想可直接应用：

- **Stage 1（课程式，~25%）**：按 FineWeb-Edu 教育分数从低到高排序通用语料，代码与数学独立交错
- **Stage 2（全混合，~75%）**：离线全局打乱全量混合，增加代码/数学比例

### 4.3 体量规划（YuFormer 小规模示例）

| 规模 | 总 tokens | Stage 1 | Stage 2 | 备注 |
|---|---|---|---|---|
| 极小（验证管线） | 10B | 2.5B | 7.5B | 单机可跑 |
| 小 | 100B | 25B | 75B | 小集群 |
| 中 | 500B | 125B | 375B | 多节点 |

## 五、下载与验证

### 5.1 环境配置

```bash
# 安装 huggingface-cli
pip install huggingface_hub

# 设置 HF 镜像（国内网络必须）
export HF_ENDPOINT=https://hf-mirror.com

# 设置数据根目录
export YUFORMER_DATA_ROOT=/data/yuformer/data
mkdir -p $YUFORMER_DATA_ROOT
```

### 5.2 批量下载脚本（核心源）

```bash
#!/bin/bash
# scripts/download_pretrain_data.sh
set -e
export HF_ENDPOINT=https://hf-mirror.com
DATA_ROOT=${YUFORMER_DATA_ROOT:-./data}
mkdir -p $DATA_ROOT

# 通用网页
huggingface-cli download HuggingFaceFW/fineweb-edu --repo-type dataset \
  --local-dir $DATA_ROOT/fineweb-edu

# 代码（Python 子集示例）
huggingface-cli download bigcode/the-stack-v2-dedup --repo-type dataset \
  --local-dir $DATA_ROOT/the-stack-v2-dedup --include "data/python/*"

# 数学
huggingface-cli download EleutherAI/proof-pile-2 --repo-type dataset \
  --local-dir $DATA_ROOT/proof-pile-2

# 学术
huggingface-cli download allenai/peS2o --repo-type dataset \
  --local-dir $DATA_ROOT/pes2o

# 百科（英文+中文）
huggingface-cli download wikimedia/wikipedia --repo-type dataset \
  --local-dir $DATA_ROOT/wikipedia --include "20231101.en/*" "20231101.zh/*"

# 文学
huggingface-cli download deepmind/pg19 --repo-type dataset \
  --local-dir $DATA_ROOT/pg19

# 中文
huggingface-cli download Skywork/SkyPile-150B --repo-type dataset \
  --local-dir $DATA_ROOT/skypile-150b

echo "Download complete. Verify with:"
echo "  du -sh $DATA_ROOT/*"
```

### 5.3 验证清单

每个数据集下载后应验证：
- [ ] 文件完整性（`du -sh` 与预期体量对比）
- [ ] JSONL 可解析（`head -1 | python3 -m json.tool`）
- [ ] 语言覆盖（抽查若干条确认语言）
- [ ] 去污染（与评测集 MMLU/GSM8K/MATH 做字符串重叠检测）

## 六、与 ZGCM 的对比

| 维度 | ZGCM | YuFormer |
|---|---|---|
| 数据公开度 | 仅 3 个 profile 描述性名称 + 8 个 SFT 源名 | **全领域精确 HF 路径 + 体量 + 许可证 + 下载命令** |
| 数据源可复现 | ❌ 无法直接下载（HF `zgcagi/ZGCM-1-Data` 是处理后的） | ✅ 一键下载原始源 |
| 配比公开 | 仅"increased code and math"描述 | ✅ 具体百分比建议 |
| 课程排序键 | 词汇复杂度（公式未公开） | FineWeb-Edu 教育分数（公开可算） |
| 中文覆盖 | 未明确 | 明确 SkyPile-150B + CCI3-HQ |

**YuFormer 的贡献**：将"ZGCM 用了什么数据"这个黑盒彻底打开——每个领域锁定到具体 HF 路径，任何人可一键下载复现，并给出了可执行的配比方案。

## 七、待决问题（供审核）

1. **目标语言**：纯英文 / 中英双语 / 多语言？影响中文占比和是否纳入 FineWeb-2
2. **体量目标**：10B / 100B / 500B？影响数据集选取（小规模可只取子集）
3. **代码语言范围**：全量 vs Python+Java+CPP+JS 主流？影响下载量
4. **是否纳入 arXiv LaTeX 独立源**：还是用 Proof-Pile-2 内含的即可
5. **配比是否做消融实验**：若做，需设计多组配比的训练实验
6. **课程排序键**：FineWeb-Edu 教育分数 vs 自研词汇复杂度 vs 困惑度排序？
