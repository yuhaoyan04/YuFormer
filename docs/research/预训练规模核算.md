# YuFormer 预训练规模核算（2026-10-20 v2）

> 约束条件（用户锁定）：总项目周期 **1–2 个月**；pretrain **≤ 45 天**（超期算力不支持）；
> 路线：**小模型 + 超大数据量**（高质量清洗池上超量训练）。

## 一、算力底盘

| 项 | 值 |
|---|---|
| GPU | 4×H800 80GB（BF16 dense ~989 TFLOPS/卡，峰值 ~3.96 PFLOPS） |
| 现实 MFU（自研框架，FSDP + SDPA） | 30%（保守）/ 35%（中枢）/ 40%（乐观） |
| FLOPs/token | 6N（4K 上下文无需激活重算；midtrain 长上下文重算另计） |
| 45 天可用算量 @MFU35% | 5.4e21 FLOPs |

## 二、可行域：45 天能训多少（模型规模 × 数据量）

| 模型 | MFU30% | MFU35% | MFU40% | tok/param@35% | 判定 |
|---|---|---|---|---|---|
| 0.3B | 2.56T | 2.99T | 3.42T | 9,969 | 小模型 MFU 易掉（通信占比高），风险大 |
| 0.4B | 1.92T | **2.24T** | 2.56T | 5,608 | ✅ 激进备选（~50B tok/天） |
| **0.5B** | 1.54T | **1.79T** | 2.05T | **3,589** | ✅ **推荐主配置**（~40B tok/天） |
| 0.6B | 1.28T | 1.50T | 1.71T | 2,492 | 可接受 |
| 0.7B | 1.10T | 1.28T | 1.46T | 1,831 | 偏保守 |
| 1.0B | 0.77T | 0.90T | 1.03T | 897 | 失去"超量训练"意义 |

**当前主候选：0.5B 模型 × 约 1T final-tokenizer tokens。** 这是数据容量与时间可行的工程候选，E1 完成前不称为 scaling-optimal。

- 训练账目：50B warmup + 800B stable + 150B anneal；三段均为 4K context，优化器状态连续。
- context extension 独立计费：16K 30B + 64K 20B；与直接 64K/50B 做 matched-token 对照。
- 1T 对 0.5B 约为 2,000 tokens/parameter，属于推理成本导向的超量训练候选。
- S5 `n_tokens` 是选择口径；正式消费量必须由 gated 64K tokenizer 的 stream meta 闭合。

## 三、供给侧：2.447T 正式治理池 → 1T 分阶段消费

清洗哲学（锁定）：**严格清洗但低丢弃**——硬 drop 只给明确的垃圾（乱码/模板/boilerplate/PII/完整性破坏），预计 drop 率 10-15%；质量好坏不做硬切，而是**全量打分排序**，由 top-k 选取决定谁进训练集。

正式源范围的逐域容量、top-10% 候选量和配额见 [`数据配比方案.md`](数据配比方案.md)。当前治理池合计 2.447T reference tokens，实测 top-10% 候选合计 287.104B。

三阶段 macro curriculum：

- **Stage A（50B）**：按域高质量前缀、多领域 warmup；LR 线性升至 peak。
- **Stage B（800B）**：按域 hybrid_v2 质量前缀组成 stable 主力段；LR 恒定。
- **Stage C（150B）**：大域 top-10%、精选小域显式加深的高质量重放，提高代码/数学/学术占比；LR 衰减。

Stage A/C 与 Stage B 的重叠是显式重放，不能把 1T consumption 宣称为 1T unique tokens。
发布门禁同时保留两套证据：完整候选序表的 doc_id/reference-token occurrence ledger，以及
正式 tokenizer 流逐文档长度账本导出的实际消费区间。后者严格按 causal loader 的监督 target
区间 `[1, stage_sample_limit × seq_len + 1)` 计算区间并集与重复量，包含首尾部分文档，要求
三阶段实际监督 token 总和与冻结配置完全相等且重放比例不超过 20%。

## 四、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 正式后端 MFU 不及预期（<30%） | 1T wall time 上升 | 1B-token pilot 实测定版；E1 按有效算力重算预算 |
| 清洗吞吐不足（19TB 输入） | 挤占训练窗口 | 176 核并行分片；清洗与 smoke 训练重叠进行；质量分类器先用规则/fasttext 轻量版 |
| tokenizer 自训 + 全池 tokenize 耗时 | 挤占训练窗口 | BPE 训练用 50GB 子采样；tokenize 按 shard 176 核并行（est. 1–2 天） |
| Muon 优化器（+~30% 等效速度，ZGCM 数据） | 错过则时间紧 | 列为 pretrain 模块一等公民，AdamW 为 fallback；首两周完成对比实验 |
| 数据质量波动导致 loss 劣化 | 浪费训练时间 | 三态审计 + 每 shard summary；课程段末尾设 eval checkpoint |

## 五、研究实验程序（2026-09-16 v2 锁定：**scaling → 架构 → 配比**，先于最终 pretrain）

最终配置由三组实验数据决定；实验顺序保证控制变量干净：**scaling 用固定数据分布 → 架构消融固定数据 → 配比响应固定架构+数据量**。当前 0.5B×1T 是主候选，实验后修正。

### 前置实验数据基座（S6 物化）

从打分池 M3 档（top-10% 质量）**确定性切出 ~100B tokens 前置实验子集**（单一固定分布——所有 scaling/架构实验共用同一批数据，保证可比性；D 轴通过其子采样实现 1B/3B/10B/30B/100B 梯度）。held-out val set 在其内按领域切出（S6 职责）。

### E1 缩放律实验（复现 OpenAI/Kaplan、Chinchilla、Google 式完整曲线）

三条轴，全部测下游表现（轻量基准 + val loss）：

| 轴 | 设计 | 臂数 × 单臂耗时 | 小计 |
|---|---|---|---|
| **固定 D=10B，变 N** | N ∈ {50M, 100M, 200M, 400M, 800M} | 5 × 1-10h | ~1 天 |
| **固定 N=300M，变 D** | D ∈ {1B, 3B, 10B, 30B, 100B}（同一分布子采样） | 5 × 0.5-36h | ~2 天 |
| **固定算力 C（isoflop），变 (N,D)** | C' = 4 GPU·天/组，N ∈ {50M,100M,200M,400M,600M} + off-grid 验证点 | ~10 组 × ~1 天 wall | ~2 周 |

- **拟合**：L(N, D) = E + A/N^α + B/D^β（Chinchilla 形式）+ Kaplan 式 L(N) 幂律对照；loss 与**下游任务表现**双轨拟合（不只看 loss——对齐"下游表现 vs size/数据"的诉求）
- **产出**：完整 scaling law 曲线族（三条轴 × loss/下游双指标）+ 外推 45 天预算的 (N*, D*) 前沿 + 数据量-模型量比值 D/N 的边际收益分析
- 耗时 ≈ **2.5-3 周**（isoflop 段为主）

### E2 架构消融实验（固定数据集 10B，iso-param ~400M，变形状）

数据：前置实验子集 10B 固定；模型：总参数配平，单变量扫描：

| 臂 | 变量 | 扫描点（iso-param 配平方式） | 检验假设 |
|---|---|---|---|
| E2-A0 | 默认形状 | pretrain-0.5b：32L / h1024 / ffn2.75× / 16Q8KV | 基线 |
| E2-A1 | tied vs untied | 同形状换 tie 开关（540M，注明 +14%）| 小模型 tied 的收益 |
| E2-A2 | 深度 | L ∈ {16, 48}（反向调 h/ffn 配平） | depth-vs-width 权衡 |
| E2-A3 | 宽度 | h ∈ {768, 1280}（反向调 L/ffn 配平） | 同上补充 |
| E2-A4 | MLP 比例 | ffn = 2× / 4× hidden（调 L 配平） | attention:MLP 算力分配 |
| E2-A5 | 全局层密度 | attention_every ∈ {3, 12}（5→11 或 3 个全局层） | 滑窗/全局配比 |
| E2-A6 | 滑窗大小 | window ∈ {64, 256} | 局部感受野甜点 |
| E2-A7 | 门控开关 | attention_output_gate off | ZGCM 门控贡献量化 |
| E2-A8 | QK-norm 开关 | qk_norm off | QK-norm 贡献量化 |
| E2-A9 | rope_percent | 0.5 / 1.0 | 部分旋转的收益 |

- 10 个唯一架构点，每点 3 seeds，共 30 臂；每臂 10B tokens。先由 E1 scaling law 将损失
  归一到统一参数量，再按跨 seed 均值和方差排序；实际墙钟由 LR pilot 吞吐回填。
- 产出：~0.5B 规模最优形状；**与默认形状冲突时以 E2 为准**

### E3 数据配比实验（固定架构 + 固定数据量，mixture response）

架构与每臂数据量（10-20B）固定，只变领域组成：

- 臂集合沿用 [`数据配比方案.md`](数据配比方案.md) 的 M1/M2/M3 + 八臂设计（±code/±math/±chinese、质量档、课程式开关、打分器消融）
- 产出：mixture response 曲线 + 最终 pretrain 领域配比
- 耗时 ≈ **2 周**（4 臂/轮并行）

### 实验总结论 → 最终 pretrain 配置

E1 定 (N, D) → E2 定形状 → E3 定配比，三者写入报告"最终配置决策链"章节，pretrain 按此开训。

## 时间线影响（必须面对的现实）

| 方案 | 数据管线 | E1+E2+E3 | 最终 pretrain | posttrain+报告 | **总计** |
|---|---|---|---|---|---|
| **A 完整版（当前执行路线）** | 10 天 | **由 LR pilot 实测重算**（E1 24 臂 + E2 10 点×3 seeds + E3 配比八臂） | 40-45 天 | ~10 天 | pilot 后冻结 |

## 七、备选预案

- **P1（MFU 理想）**：E2 外推上调 token 量，打满 45 天
- **P2（MFU 不理想）**：按 E2 前沿降 N 或降 D
- **P3（时间进一步压缩）**：保持课程比例，等比缩短实际 token budget
- **P4（实验结论意外）**：E1/E2 结论与 0.5B×1T 先验冲突时，以实验数据为准并在报告记录决策链
