# 生产观察器源码快照

`active_sources/` 保存当前外部 `/opt/yuformer-build/` 观察器的源代码副本。它们覆盖后台心跳、总工期与实际LR、原生检查点、九域验证、只读预取、长阶段检查、半日复核和外围接管。

[source_manifest.json](source_manifest.json) 同时记录原路径/原SHA与仓库副本SHA。恢复脚本中的运行租约token已脱敏，明确记录变换；其余副本逐字节一致。真实进程仍使用原路径及冻结哈希，复制没有替换或重启它们。

这些是用于复盘与复现设计的源代码快照。里面保留原工作区绝对路径、原数据/模型身份和针对该次训练的断言，不能在克隆后直接当作通用启动器。部署到新工作区时，先显式声明路径和预算，重新绑定身份、故障测试和源哈希；不要把原实验的PASS当作新部署资格。正式阶段控制器源码位于 `eval/src/yuformer_eval/context_pipeline.py`，其114文件冻结边界继续有效。

代码、运行证据与动态报告分开管理：源码副本进入Git；实际运行JSON、事件、权重和租约状态留在外部存储；轻量发布数据在 `report/metrics/`。
