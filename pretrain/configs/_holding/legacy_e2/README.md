# Legacy E2 configuration

`e2_l16_lf` was a compatibility-trainer memory/performance variant, not an architecture-controlled
E2 arm. It used the old Muon + constant-LR recipe, lacked data release/EOD requirements, and had no
formal backend identity. It is retained only for historical comparison and must not be launched as
an E2 result. Current E1/E2 configs are generated by
`experiments/_common/gen_e1e2_arms.py` and fail closed on the pinned TorchTitan backend and PASS data
release.
